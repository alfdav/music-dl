# DJAI modules

DJAI is the music-dl GUI home for automation modules. It is not a Settings page.

DJAI modules that use AI can make mistakes. Verify important actions yourself before you confirm them.

## Discord Bot

Deploy and control the private voice bot against this music-dl server. The bot does not judge Clean Up deletes.

See [`bot-onboarding.md`](bot-onboarding.md).

## Edition advice (Jev)

Advisory TypeSafe Jev chips on Clean Up. Enable the module on the DJAI card, not in Settings.

AI suggestions can be wrong. Treat edition advice as advisory. Confirm paths yourself (Reveal in Finder) before Clean Up. music-dl never promises a suggestion is safe to delete.

See [`djai-edition-advice.md`](djai-edition-advice.md).
